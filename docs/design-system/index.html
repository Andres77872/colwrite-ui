Reference

ColWrite design system

A dark-first system for a scientific block editor with an AI assistant. Every token, primitive and screen below is a faithful reproduction of the shipping app: surfaces tuned against #0a0a0f, one filled-accent split for contrast, and a review-first interaction model where nothing the assistant writes reaches the document without an explicit accept.

Principle 01

Single-mode dark

No light palette. Shadows, scrollbars, scrims and the eight chart series are validated against one background; a palette flip alone would not produce a working theme.

Principle 02

Contrast splits the accent

primary carries text, borders and washes. primary-strong fills surfaces that hold white labels — 6.3:1 where the lighter hue managed 4.47:1.

Principle 03

Meaning never rests on hue

Diffs pair a background with a foreground and a real <ins>/<del>. Change cards name their kind in words. Icons are decorative; text carries it.

Review workflow

The assistant proposes. You dispose.

Ask the assistant to rewrite, restructure or draft — every edit lands in the document as a suggested change, right where it would appear.

  • Word-level diffs show exactly what moved — additions, rewrites, deletions, moves and title changes.
  • Accept or reject each change where it lands, or work through the batch from the review bar.
  • Dependent changes stay locked until the change they build on is accepted.
  • Chat with the document: reference it with #, then ask for rewrites, structure, summaries or references.
